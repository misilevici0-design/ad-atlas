# AD Atlas Minimap v0.3

Внешняя прозрачная миникарта для FiveM. Не внедряется в процесс игры и не требует установки ресурса на сервер.

## Управление

- `F8` — показать или скрыть миникарту.
- `F9` — закрепить окно и включить пропуск кликов в игру.
- `F10` — открыть или скрыть настройки.

После запуска нажмите в меню сервера «Собрать координаты». Программа распознаёт три числа из буфера обмена и переводит их в пиксели по точным границам штатной карты GTA V: X от −4140 до 4860, Y от −5100 до 8400. Захват миникарты сопоставляет дороги с ближайшим участком `map.webp`, плавно двигает карту и блокирует ложные скачки.

Если точка всё ещё немного смещена, откройте настройки, нажмите «Исправить позицию» и один раз укажите своё место на полной карте. Поправка сохранится на компьютере. Кнопка `↺` сбрасывает её.

Если захват выбрал не FiveM, перезапустите программу после входа на сервер. Для первого запуска рекомендуется оставить настройки открытыми и только затем нажать `F9`.
