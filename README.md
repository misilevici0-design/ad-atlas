# AD Atlas

Интерактивная карта на основе AD Map: 663 исходные точки, поиск по русским названиям категорий, фильтры, список результатов, карточки локаций и локальный редактор.

## Открыть на компьютере

Распакуйте весь архив и откройте `index.html`. Установка Node.js, Python или сервера не требуется. Все библиотеки, иконки и изображение карты включены в комплект. Для постоянного использования и стабильного сохранения правок рекомендуется размещение на GitHub Pages.

## Бесплатная публикация на GitHub Pages

1. Создайте **публичный** репозиторий `ad-atlas` на GitHub.
2. Через **Add file → Upload files** загрузите содержимое папки `ad-map-plus`: `index.html` должен оказаться в корне репозитория. Все файлы опубликованной версии находятся в корне репозитория. ZIP загружать не нужно — сначала распакуйте его.
3. Нажмите **Commit changes**.
4. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку **/(root)**, нажмите **Save**.
6. Адрес сайта появится на этой же странице после завершения публикации. Обычно он выглядит как `https://ИМЯ.github.io/ad-atlas/`.

GitHub Pages доступен бесплатно для публичных репозиториев на GitHub Free. Сервер, база данных, платный домен и API-ключи не требуются. Справка: https://docs.github.com/en/pages/getting-started-with-github-pages

## Редактор

Кнопка **Редактор** включает добавление и перетаскивание точек. Нажмите на маркер → **Изменить**, чтобы изменить название, описание, координаты и категорию или удалить точку. Кнопка `⋯` у категории позволяет изменить её имя, позицию в списке или удалить её с переносом точек в «Прочее».

Правки сохраняются в localStorage этого браузера. Это локальный редактор, а не администраторский доступ: посетители не могут перезаписать общую карту через сайт. Другие браузеры и устройства этих правок не видят. Очистка данных браузера удаляет локальные правки — сохраняйте резервные копии.

## Обновить карту для всех посетителей

1. В редакторе нажмите **Экспорт**.
2. Выберите **Для публикации — data.js** и скачайте файл.
3. В своём репозитории загрузите этот `data.js` поверх прежнего и подтвердите коммит.
4. GitHub Pages опубликует обновлённую карту автоматически.

Посетители с сохранёнными личными правками продолжают видеть свою версию. Чтобы получить опубликованную карту, им нужно выбрать **Сброс правок**. Перед сбросом можно скачать резервную копию.

## Импорт и резервные копии

Экспорт **Резервная копия — JSON** содержит точки, названия категорий и их порядок. Кнопка **Импорт** принимает этот файл и исходный `points.json` AD Map. Импорт заменяет локальную карту только после подтверждения. Неверные координаты и неподходящие данные отклоняются.

## Управление

- Перетаскивание и колесо мыши / жест двумя пальцами — перемещение и масштаб.
- Кнопка `⛶` — вся карта.
- `/` — переход к поиску.
- `Esc` — закрытие карточки / отмена добавления.
- Поиск действует по включённым категориям. **Все** включает категории, **Скрыть** отключает все.
- Нажмите на карту и выберите **Копировать координаты**. В карточке точки есть отдельная кнопка координат.
- На телефоне панель открывается кнопкой `☰`.

## Файлы

- `index.html`, `style.css`, `app.js` — новый интерфейс и логика.
- `data.js` — опубликованная карта: точки, категории и порядок.
- `map.webp`, файлы значков PNG — изображение и значки исходной карты.
- `leaflet.js`, `leaflet.css`, `LEAFLET-LICENSE.txt` — Leaflet 1.9.4 и его лицензия.
